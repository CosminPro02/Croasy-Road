# 🐔 Crossy Road - 2D OpenGL Clone   

A simple 2D action game project similar with the mobile hit Crossy Road.


## About the Project

The goal of the game is to guide a chicken across a busy highway. Players must navigate through six lanes of traffic to reach the top of the screen. Each successful crossing increases your score and advances you to the next level.




Core Features

Difficulty Scaling: The game features 25 levels. With every level, the cars move faster, making the crossing more difficult.





Procedural Traffic: Cars are generated with random colors, speeds, and directions at the start of every level.




Animated Graphics: Includes a "bounce" animation for the player character and detailed car models with wheels and lights.




UI Elements: A real-time progress bar shows how close you are to winning the game.


### Built With

C++: The core logic and object-oriented structure.


FreeGLUT (OpenGL): Used for rendering 2D shapes, handling window events, and managing animations.



Visual Studio Code: The primary development environment.

### How to Play

The controls are straightforward and use the keyboard:


Up Arrow: Move forward (and restart if the game is over).



Down Arrow: Move backward.



Left/Right Arrows: Move sideways.



Objective: Reach a score of 25 points without getting hit by a car to win. If a collision occurs, it is "Game Over".
